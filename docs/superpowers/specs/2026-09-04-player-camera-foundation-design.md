# 플레이어 일반 카메라 기반 설계

## 목적

현재 `ATalPlayerCharacter`에 직접 들어 있는 기본 스프링암 카메라를 중앙 구도의 3인칭 궤도 카메라로 확장한다. 일반 카메라가 화면 데드존을 기준으로 플레이어를 부드럽게 다시 추적하고, 이후 락온 카메라가 동일한 기반 위에서 제어권을 안전하게 넘겨받을 수 있게 한다.

## 범위

이번 단계에서 구현한다.

- 캡슐에 부착되는 조절 가능한 가상 목 지점 `CameraTarget`
- 일반 카메라 동작을 소유하는 `UNTPlayerCameraControllerComponent`
- 중앙 구도의 스프링암 카메라
- 조절 가능한 카메라 거리와 거리 보간 속도
- X/Y 회전 감도와 Pitch 범위 제한
- 화면 데드존 이탈 시 자동 추적
- 수동 카메라 입력 직후 자동 추적 억제
- 개발용 화면 데드존 디버그 표시
- 향후 락온 모드가 카메라 제어권을 넘겨받을 수 있는 모드 인터페이스
- 카메라 수학 함수에 대한 Unreal Automation 테스트

이번 단계에서 구현하지 않는다.

- 적 탐색, 락온 유지 및 대상 전환
- 락온 HUD
- 락온 중 캐릭터 스트레이핑
- 벽 충돌의 진입 속도와 복귀 속도 분리
- 플레이어, 프롭 및 적의 디더 페이드
- 게임 설정 UI와 사용자 설정 저장

## 구조

### `ATalPlayerCharacter`

캐릭터는 카메라 구성 요소를 생성하고 입력을 전달한다.

- `CameraTarget`은 `RootComponent`에 부착되는 `USceneComponent`다.
- 기본 상대 위치는 `(0, 0, 80)`이며 블루프린트에서 조절할 수 있다.
- `CameraBoom`은 `CameraTarget`에 부착한다.
- `FollowCamera`는 기존과 같이 `CameraBoom` 소켓에 부착한다.
- 기존 `Look` 입력은 입력값을 카메라 컨트롤러 컴포넌트에 전달한다.
- 이동, 회피, 공격, 상호작용 코드는 변경하지 않는다.

### `UNTPlayerCameraControllerComponent`

일반 카메라의 상태와 갱신을 담당하는 액터 컴포넌트다. 캐릭터의 전투 및 이동 로직과 카메라 계산을 분리한다.

컴포넌트는 다음 참조를 초기화 시 받는다.

- 소유 캐릭터
- `CameraTarget`
- `CameraBoom`
- `FollowCamera`

컴포넌트가 제공하는 공개 동작은 다음과 같다.

- `InitializeCamera(...)`
- `HandleLookInput(const FVector2D& LookInput)`
- `SetCameraMode(ENTPlayerCameraMode NewMode)`
- `SetDesiredCameraDistance(float NewDistance)`
- `SetHorizontalSensitivity(float NewSensitivity)`
- `SetVerticalSensitivity(float NewSensitivity)`

`ENTPlayerCameraMode`는 우선 `Free`와 `LockOn`을 정의한다. 이번 단계에서는 `Free`만 완전하게 동작한다. `LockOn`으로 전환하면 일반 카메라의 수동 입력과 자동 추적이 중지되어 다음 단계의 락온 시스템이 회전을 소유할 수 있다.

## 카메라 설정값

다음 값은 `EditAnywhere` 또는 `EditDefaultsOnly`로 블루프린트에 노출한다.

| 설정 | 기본값 | 유효 범위 |
| --- | ---: | ---: |
| 카메라 거리 | 350 cm | 0 이상 |
| 거리 보간 속도 | 10 | 0 이상 |
| 수평 감도 | 50 | 0~100 |
| 수직 감도 | 50 | 0~100 |
| 최소 Pitch | -60도 | -89~89 |
| 최대 Pitch | 60도 | -89~89, 최소값 이상 |
| 데드존 너비 | 화면의 10% | 0~100% |
| 데드존 높이 | 화면의 10% | 0~100% |
| 자동 추적 속도 | 8 | 0 이상 |
| 수동 입력 억제 시간 | 0.75초 | 0 이상 |

감도 `50`은 배율 `1.0`으로 환산한다. `0`은 회전을 멈추고 `100`은 배율 `2.0`으로 환산한다. 수평과 수직 감도는 독립적으로 적용한다.

## 일반 카메라 데이터 흐름

1. `IA_Look`의 2D 입력이 캐릭터의 `Look`에 전달된다.
2. 캐릭터는 입력값을 `UNTPlayerCameraControllerComponent::HandleLookInput`에 전달한다.
3. 컴포넌트는 감도 배율을 적용하고 컨트롤러 Yaw/Pitch를 갱신한다.
4. Pitch는 설정된 최소값과 최대값 사이로 제한한다.
5. 유효한 수동 입력이 들어오면 마지막 수동 입력 시간을 기록한다.
6. Tick에서 `CameraBoom->TargetArmLength`를 목표 거리로 보간한다.
7. 수동 입력 억제 시간이 지난 뒤 `CameraTarget`을 화면 좌표로 투영한다.
8. 화면 좌표가 데드존 내부이면 회전을 변경하지 않는다.
9. 화면 좌표가 데드존 밖이면 카메라에서 `CameraTarget`을 바라보는 회전을 계산하고, 경계 초과량과 추적 커브를 반영해 컨트롤 회전을 보간한다.

## 화면 데드존

데드존 크기는 뷰포트 너비와 높이에 대한 백분율이다. 너비와 높이를 각각 `10`으로 설정하면 1920x1080 화면에서 192x108 크기의 중앙 사각형이 된다.

화면 좌표는 뷰포트 중심을 원점으로 하는 정규화 좌표로 변환한다. 데드존 경계 초과량은 축별로 계산한다.

- 내부 또는 경계에서는 초과량이 `(0, 0)`이다.
- 오른쪽 또는 아래쪽 이탈은 양수다.
- 왼쪽 또는 위쪽 이탈은 음수다.
- 뷰포트 크기가 0이거나 투영에 실패하면 해당 프레임의 자동 추적을 건너뛴다.

추적 커브가 지정되어 있으면 정규화된 경계 초과량을 커브 입력으로 사용한다. 커브가 없으면 선형값을 사용한다.

## 수동 입력과 자동 추적의 충돌 방지

수동 입력 크기가 작은 노이즈 기준값을 넘으면 자동 추적 억제 타이머를 갱신한다. 억제 시간 동안 자동 추적은 회전을 변경하지 않는다. 이를 통해 사용자가 카메라를 돌리는 중 자동 추적이 반대 방향으로 끌어당기는 현상을 막는다.

자동 추적은 `Free` 모드에서만 실행한다. `LockOn` 모드에서는 다음 단계의 락온 시스템이 카메라 회전을 전담한다.

## 디버그 표시

디버그 표시가 활성화되고 로컬 플레이어 뷰포트가 유효할 때 중앙 데드존 사각형을 화면에 그린다. 이 기능은 개발 및 에디터 빌드에서만 사용하며 기본값은 꺼짐이다. Shipping 빌드의 게임플레이 동작은 디버그 표시 여부에 의존하지 않는다.

## 오류 및 경계 처리

- 카메라 참조가 아직 초기화되지 않았으면 입력과 Tick 갱신을 안전하게 건너뛴다.
- 카메라 거리는 0 이상으로 제한한다.
- 감도는 0~100으로 제한한다.
- Pitch 범위는 -89~89도로 제한하고 최소값이 최대값을 넘지 않게 정규화한다.
- 로컬 플레이어 또는 뷰포트가 없으면 화면 투영과 디버그 표시를 건너뛴다.
- `CameraTarget`이 없으면 자동 추적을 실행하지 않는다.

## 테스트 전략

카메라 계산 중 엔진 월드가 필요 없는 로직은 순수 함수로 분리한다.

- 감도 0, 50, 100이 각각 0.0, 1.0, 2.0 배율을 반환한다.
- 감도 범위를 벗어난 값이 0~100으로 제한된다.
- 데드존 내부 좌표는 초과량 0을 반환한다.
- 데드존의 좌우 및 상하 바깥 좌표는 올바른 부호의 초과량을 반환한다.
- 0%와 100% 데드존 경계를 처리한다.
- Pitch가 설정 범위를 벗어나지 않는다.
- 잘못된 Pitch 최소·최대 입력이 유효한 범위로 정규화된다.

통합 검증에서는 다음을 확인한다.

- 프로젝트가 Unreal Engine 5.8에서 컴파일된다.
- 카메라 자동화 테스트가 통과한다.
- `BP_TalPlayerCharacter`가 기존 입력 액션과 에셋 참조를 유지한다.
- 일반 모드에서 수동 회전, 거리 보간 및 데드존 자동 추적이 동작한다.
- 모드를 `LockOn`으로 바꾸면 일반 카메라가 회전에 개입하지 않는다.

## 완료 기준

- 중앙 구도의 일반 카메라가 기존 캐릭터에서 동작한다.
- 카메라 설정값을 블루프린트에서 조절할 수 있다.
- 수동 입력 중 자동 추적이 카메라와 싸우지 않는다.
- 추적 대상이 데드존을 벗어날 때만 부드럽게 중앙 방향으로 복귀한다.
- Pitch 제한과 카메라 거리가 설정 범위를 지킨다.
- 락온 단계가 `LockOn` 모드를 통해 일반 카메라 제어를 중지시킬 수 있다.
- 자동화 테스트와 프로젝트 빌드가 통과한다.
